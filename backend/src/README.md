# Backend source

Chứa các project C# triển khai ứng dụng MVC theo lớp. Web tiếp nhận yêu cầu và hiển thị Razor views; Application xử lý use case; Domain giữ mô hình và quy tắc nghiệp vụ; Infrastructure triển khai lưu trữ và tích hợp.

- `SportsCourtBooking.Web/` (web cho khách hàng, chủ sân, nhân viên)
- `SportsCourtBooking.Desktop/` (ứng dụng WinForms cho quản trị viên)
- `SportsCourtBooking.Application/`
- `SportsCourtBooking.Domain/`
- `SportsCourtBooking.Infrastructure/`
