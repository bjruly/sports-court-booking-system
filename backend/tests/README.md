# Backend tests

Project `SportsCourtBooking.Tests/` dùng xUnit để kiểm thử tự động backend, bao gồm kiểm thử đơn vị cho quy tắc miền/use case và kiểm thử tích hợp khi các dịch vụ tương ứng được triển khai.

Project test đã được nối với Domain và Application. Các bài kiểm thử nghiệp vụ sẽ được bổ sung cùng với những use case đầu tiên.
